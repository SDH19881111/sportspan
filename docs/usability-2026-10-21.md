# 사용성 점검 기록 (2026-10-21)

실제 브라우저 창에서 설명판 3개(피구·이어달리기·교실)를 만들어 보며 찾은 문제와 수정 우선순위.
화면 크기 1366×768 / 1280×720 / 1024×768에서 확인했다.

상태: ☐ 할 일 · ◐ 진행 중 · ☑ 완료

## 1순위 — 발표가 막히거나 데이터가 몰래 바뀜

| # | 상태 | 문제 | 원인·위치 |
|---|---|---|---|
| P1-1 | ☑ | "이동 경로" 도구가 끌어서 이동을 만든 뒤에도 켜진 채 남음 → 다시 누르면 꺼지고, 이어서 끌면 학생 **출발 위치가 말없이 옮겨짐** | 바닥 클릭 방식만 `setTool(select)`, 끌기 방식(`EditorScene.tsx` onItemDown path)은 안 함 |
| P1-2 | ☑ | 시작을 "클릭할 때"로 해도 재생이 멈추지 않고 끝까지 흐름 (PPT식 단계 진행 불가) | `waitsForClick`이 재생 루프(`EditorScene.tsx` PlaybackScene)에서 안 쓰임 |
| P1-3 | ☑ | 장면 끝나고 0.8초 뒤 다음 장면/편집 화면으로 넘어감. 끝난 모습·자막을 두고 설명할 수 없음 | `HOLD = 0.8`, `playing.all`이면 자동 진행 |
| P1-4 | ☑ | 발표 화면이 따로 없음. 재생 중에도 도구·속성·장면 띠가 보이고 전체 화면 없음 | — |

> P1-2·3·4는 "발표 모드"(`src/present/`)로 해결: 위쪽 ▶ 발표(F5 처음부터, Shift+F5 지금 장면부터) → 전체 화면에 장면과 큰 자막만.
> 클릭·Space·→·PageDown 다음, ←·PageUp 이전(앞 장면은 끝난 모습으로), Home 처음, Esc 나가기(보던 장면으로 돌아감).
> "클릭할 때" 묶음마다, 장면 끝마다 멈춘다. 도는 중에 누르면 그 묶음을 끝까지 건너뛴다. 끌면 시점만 돈다.
> 편집 화면의 "이 장면/처음부터"는 미리보기라 예전처럼 끝까지 이어서 튼다.
> 남은 확인: 실제 Chrome에서 전체 화면 켜짐(미리보기 브라우저는 도구 클릭을 사용자 동작으로 안 쳐서 확인 못 함 — 못 켜면 창 안에서 발표됨).

| # | 상태 | 문제 | 원인·위치 |

| P2-6 | ☑ | 도구 안내 문구가 왼쪽 패널 맨 아래(912px)라 768 높이에서 안 보임 | `.palette .tip` |
| P2-8 | ☑ | 장면 띠 오른쪽 ◀ ▶가 '장면 순서 바꾸기'인데 앞/뒤 장면 넘기기처럼 보임(눌렀다가 순서가 바뀔 수 있음) | `SceneStrip.tsx` scene-tools |
| P2-7 | ☑ | 자막 칸 한 줄짜리(긴 설명 잘림), 편집 중 코트 아래 15%를 덮음 | `App.tsx` caption-edit input |

> P2-1·2·3 해결: `.center` 열과 `.row2`를 `minmax(0, 1fr)`로(캔버스·숫자 칸이 줄어들 수 있게), 속성 패널 `scrollbar-gutter: stable`·애니메이션 머리줄 줄바꿈,
> 1200px 이하에서 양쪽 패널 168/264px·장면 카드 축소. P4-2는 두 칸 도구 버튼을 아이콘 위·이름 아래로.
> 점검: 1920·1366·1280·1100·1024·860 너비 × 6가지 패널 상태에서 넘침·잘림·캔버스 겹침·도구 이름 끊김 0건(새로고침 없이 줄였다 늘였다).

> P2-4~8 해결: 말풍선을 머리 위 20px 더 띄움(+자연 폭·줄바꿈 유지), '위에서'는 아주 조금 남쪽에서 내려다보고 도착 때 정확히 맞춤,
> 도구 안내를 3D 화면 위쪽에(고르기일 땐 끌기·Ctrl+끌기·Shift 한 줄 → P3-6도 해결), 자막 칸을 쓴 만큼 늘어나는 여러 줄 칸으로(Enter 줄 바꿈, 발표·재생 자막도 줄 유지),
> 장면 띠 ◀ ▶ 위에 '장면 순서' 이름표. 점검: 1920·1366·1280·1100·1024·860 × 7가지 상태 넘침·겹침 0건, 말풍선 단 학생 실제 클릭으로 고르기 3/3.

## 3순위 — 만들기 번거로움

| # | 상태 | 문제 |
|---|---|---|
| P3-1 | ☑ | 운동장(40×25m)에서 학생·콘이 너무 작고 주황 콘이 흙바닥에 묻힘. 공은 체육관에서도 작음 |
| P3-2 | ☑ | 새 바닥에 경기장 선이 없음(피구 코트·트랙·출발선 매번 그림). 견본은 콘 축구 하나 |
| P3-3 | ☑ | 새로 만들면 이름이 모두 "새 활동", 실수로 만든 빈 판도 저장됨 |
| P3-4 | ☑ | 학생 처음 방향이 모두 같음, 좌우 뒤집기 없음 |
| P3-5 | ☑ | 이동마다 도구 다시 골라야 함, 30m 달리기 1배속 9.5초로 김 |
| P3-6 | ☑ | 빈 바닥 끌기 = 화면 회전. Ctrl+끌기(여러 개 고르기) 안내가 안 보임 |

> P3-1~5 해결(2026-10-22):
> - P3-1: 그릴 때만 키우는 배율(`catalog.ts` viewScale). 운동장에서 학생 1.4배·작은 장비 1.8배, 공은 체육관 1.6배·운동장 2.2배.
>   콘·접시콘·공 등 작은 장비 발밑에 어두운 그림자 원. 자리·거리·움직임 계산은 실제 크기 그대로.
> - P3-2: 속성 탭(아무것도 안 골랐을 때) **경기장 선**: 없음/피구/달리기/트랙/축구(`model/courts.ts`). 바닥 크기에 맞춰 긋고,
>   한 묶음으로 고정(학생을 끌 때 선이 대신 골라지지 않게). 장소·크기를 바꾸면 다시 맞춰 긋는다.
> - P3-3: 새 판 이름은 "운동장 활동 3"처럼 장소+다음 번호. 아무것도 안 만든 판은 저장하지 않고(위쪽에 "빈 설명판은 무엇이든 놓으면 저장됩니다"),
>   다 지워 빈 판이 되면 목록에서도 뺀다(`library.ts` isBlank·saveUnlessBlank). 새로고침하면 마지막에 저장된 판으로.
> - P3-4: 새 학생은 경기장 가운데 쪽을 본다(왼편 →, 오른편 ←로 두 팀이 마주 섬). 배치에 **좌우 뒤집기(H)·앞뒤 뒤집기(V)**:
>   고른 것들 가운데를 기준으로 자리·보는 방향·이 장면의 이동 경로까지 거울처럼.
> - P3-5: 왼쪽 "이동 경로" 도구는 끌어서 이동을 만든 뒤에도 켜져 있어 여러 학생을 이어서 그린다(Esc로 끝, 화면 위 안내에 표시).
>   P1-1(켜진 줄 모르고 끌어 출발 자리가 옮겨짐)은 눌린 버튼·안내 문구로 켜져 있음을 늘 보여 주는 것으로 대신 막는다.
>   뛰기 최고 빠르기 3 → 4.5m/s(가속 2.5 → 3.5): 30m가 11.2초 → 약 7.9초. 걷기는 그대로.
> 점검: `tests/making.test.ts` 12개, 실제 브라우저 1366×768에서 운동장 판 만들기·피구 선·학생 방향·이동 두 번 연달아·H 뒤집기·빈 판 새로고침.

## 사용해 보며 추가된 요청

| # | 상태 | 내용 |
|---|---|---|
| R-1 | ☑ | 여러 명을 골라 한 곳으로 이동 → **모여 이동**: 누른 자리는 비우고 한 칸(격자 크기) 띄워 둥글게, 옆 사람과도 몸 사이 한 칸, 모두 동시에. 각자 오던 쪽 자리에 선다. 기존 동작은 **대형 유지** 버튼으로 남김 (`ops.ts` gatherSpots, tests/gather.test.ts) |
| R-3 | ☑ | 학생·장비를 누르거나 Ctrl+끌기로 고르면 오른쪽이 속성 탭으로(애니메이션 탭에 계속 머물던 문제). 애니메이션 번호·경로를 누를 때는 그대로 애니메이션 탭 |
| R-2 | ☑ | 말풍선 글자 쓰는 곳을 못 찾음: 말풍선 도구로 달거나 말풍선을 누르면 속성 탭으로 바뀌고 글자 칸에 바로 커서 |
| R-4 | ☑ | 고정은 하나씩 되는데 풀기는 "모두 고정 풀기"뿐이고, 고정된 것은 골라지지도 않음 → **고정된 것도 누르면 골라진다**(끌면 옮겨지지 않고 화면이 돈다). 고른 뒤 속성 패널·오른쪽 클릭 메뉴에서 하나씩 "고정 풀기". 고정된 것은 옮기기·돌리기·뒤집기·지우기에서 빠진다. 끌어서 고르기(Ctrl+끌기)·모두 선택(Ctrl+A)에는 안 들어간다(경기장 선 틀이 딸려 오지 않게) |
| R-5 | ☑ | **오른쪽 클릭 빠른 메뉴**(`editor/ContextMenu.tsx`): 물건 위 = 잘라내기·복사·붙여넣기·복제·지우기, 고정·묶기, 돌리기·뒤집기, 이동 애니메이션·강조·말풍선, 이름 고치기, 팀 바꾸기. 빈 바닥 = 여기에 붙여넣기·모두 선택·새 장면·모두 고정 풀기. 오른쪽 버튼으로 끌면 예전처럼 화면 옮기기(누른 자리에서 뗄 때만 메뉴) |
| R-6 | ☑ | **윈도우·PPT식 단축키**: Ctrl+A 모두 선택, Ctrl+O 내 설명판, Ctrl+M 새 장면, F2 이름 고치기, Tab/Shift+Tab 다음·이전 것 고르기(작업판 위에 마우스가 있을 때), Home/End 첫·마지막 장면, Shift+방향키 격자 한 칸, 글자 칸에서 Esc = 칸에서 나오기. 단축키 동작은 `editor/actions.ts`로 모아 메뉴와 함께 씀 |
